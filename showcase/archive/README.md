# Historical media archive

These pre-migration recordings, posters, thumbnails, and dashboard captures are
preserved as historical evidence. Their embedded titles and narration use
previous product branding; they are not current Sulcus marketing assets.
Renaming a file does not update the words rendered inside it.

- `sulcus_demo.gif`: original animated dashboard demo used by the historical showcase renderer.
- `sulcus_showcase.mp4` and `sulcus_showcase_poster.png`: original narrated showcase and poster.
- `sulcus_primary_demo.mp4` and `sulcus_primary_demo_polished.mp4`: previous primary demo renders.
- `sulcus_primary_demo_thumbnail.png`: previous primary demo thumbnail.
- `sulcus_dashboard_current.png` and `sulcus_dashboard_current.svg`: dashboard snapshot used for those renders; the filename is historical.

Current dashboard captures belong in `showcase/assets/`. Rendering scripts and
companion text use the current Sulcus name. The historical showcase renderer
still uses the archived GIF as footage. These archived files are excluded from
the Python wheel and source distribution.
